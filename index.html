Import file format

Use a JSON file with an explicit node list and directed relationships. Every relationship endpoint must match a node ID. Save as UTF-8 with a .json extension.

Node kinds: user, service, role, permission, or asset. Set entry and sensitive to true or false. Sensitive elements must use kind asset. A relationship can include an optional plain-language explanation.
Import replaces the current model only when the whole file is valid. The current and imported models are compared after a successful import.
